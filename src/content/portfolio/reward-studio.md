## 這個專案在解決什麼

音樂教室的老師都懂：小朋友練琴需要動力，貼紙、集點卡是老招，但實體集點有一堆麻煩——卡片會不見、點數算不清、家長看不到進度，老師還要自己記帳。

## 我的解法

把整套獎勵機制搬到線上，做成老師專用的管理系統：

- **學生管理**：老師登入後建立自己的學生名單，每個學生有自己的帳戶
- **發放金幣**：上課表現好、回家有練琴，老師一鍵發金幣，紀錄清清楚楚
- **虛擬商店**：金幣可以兌換虛擬物品，小朋友有存錢、選擇、兌換的完整體驗
- **雲端帳號**：老師用 Email 註冊登入，資料跟著帳號走，換裝置也不怕

讓「認真練琴」看得到回報，老師省事，小朋友更有動力。

## 幕後技術

React + TypeScript + Vite；UI 用 shadcn/ui + Tailwind CSS；帳號與後端服務用 Supabase。
