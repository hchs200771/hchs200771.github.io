## 這個專案在解決什麼

節慶行銷最缺的就是「讓人願意停下來玩一下」的互動內容。文字貼文大家滑過就忘，但一個應景的小遊戲，能讓人玩上幾分鐘、順手分享給朋友。

這個專案同時也是一個示範：**用 AI Coding，一個有趣的點子可以多快變成能玩的成品**。

## 玩法

- 操控龍舟上下移動：救起屈原、收集粽子與艾草加分回血
- 閃避楚王、海龍王、毒蛇、龍捲風等障礙
- 累積分數過關，難度逐關提升
- 手機用手指拖曳，電腦用方向鍵或滑鼠，打開網頁就能玩

## 幕後技術

純 HTML + CSS + JavaScript，零依賴、不用安裝任何東西；直接部署在 GitHub Pages。
