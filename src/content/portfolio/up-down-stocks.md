## 這個專案在解決什麼

認真做功課的投資人，每天收盤後都在重複同一套苦工：整理今天哪些股票強、哪些弱，強的是不是同一個族群、背後有沒有題材、這波是剛啟動還是快結束了。這件事每天要花一小時以上，而且很容易漏看。

更麻煩的是，光看「今天漲什麼」永遠只看得到一天。真正決定行情的是**資金的輪動方向**——錢正在從哪個族群流出、流進哪裡，而這件事一天的漲跌幅根本看不出來。

## 我的解法

把整套盤後功課變成一條指令，產出一份「打開信箱就讀得完」的報告。

### 一、當日強弱族群與題材

- **自動抓資料**：收盤後抓當日市場行情與漲跌幅前後 100 名
- **AI 族群分析**：讓 AI 從漲跌名單裡歸納出當天的強勢與弱勢族群，寫出每個族群背後的產業故事與漲跌原因
- **記得歷史脈絡**：今天冒出來的新題材、已經延續好幾天的舊主流，報告裡分得清清楚楚，不會每天都當成第一天

### 二、族群輪動 RRG（這版最主要的新功能）

RRG（相對輪動圖）把每個族群相對大盤的**相對強弱**與**動能**畫在四個象限裡——領先、弱化、落後、改善——資金正在離開誰、正在進入誰，一眼就看得到。這個專案裡有四個市場可以切換：

- **台股族群輪動**：27 個自建產業籃子、共 245 檔成分股，以加權指數為基準。從晶圓代工、IC 設計、CPO 矽光子、AI 伺服器散熱，到航運、金融、生技、工具機都涵蓋
- **美股板塊輪動**：11 個 SPDR 板塊 ETF（科技、金融、能源、醫療保健…）對標普 500，看美國資金這週站在哪一邊——台股的科技權值往往跟著它走
- **全球資產輪動**：股、債、金、原物料、美元、比特幣，看的是風險偏好本身在開還是在關
- **全球市場輪動**：美、歐、日、台、陸、韓、印，看台股在全球資金競爭裡是被加碼還是被抽走

每個市場都能切 120／60／20 日三個視窗，長中短期輪動一次看完；點族群名稱會展開成分股並連到 Yahoo 股市。

**關鍵設計：族群籃子是固定的。** 成分股跟每天的 AI 分類刻意分開維護——因為籃子只要每天變動，軌跡就失去了跨日比較的意義，RRG 也就白畫了。

### 三、輪動訊號自動判讀

圖再漂亮，不會讀還是沒用。所以報告會直接把圖翻成文字結論：

- **象限清單**：今天哪些族群在領先、哪些正在弱化
- **值得注意的異動**：例如「仍在領先象限，但動能 5 日內由 102.7 降至 101.5——尚未跌出象限，屬見頂前的早期訊號，順勢單宜開始減碼而非加碼」
- **市場狀態**：當很多族群同時觸發同一種訊號，那就不是個別族群的事，而是大盤特徵，會另外收斂成一句結論

### 四、其他報告章節

國際情勢（主要指數、原物料、殖利率、匯率）、信用利差溫度計（高收益債／投等債 OAS，風險偏好最早的預警）、市場儀表板、強勢焦點、長線策略與進出場、當日操作建議。

搭配排程執行，每天收盤後報告自己送上門。

## 幕後技術

TypeScript 抓取市場資料與行情；RRG 以 JdK RS-Ratio 的開源近似自行實作，抓 Yahoo Finance 兩年還原收盤價、把族群編成等權指數再計算相對強弱與動能，並用有限併發的請求池處理 245 檔成分股的抓取；AI 分析流程由 Claude Code Skill 驅動並把族群 research 平行化；報告以 HTML 產出，透過 Google Apps Script webhook 寄信，同時發佈到 GitHub Pages 網頁版（互動圖只在網頁版）。
