## 這個專案在解決什麼

投資人每天看得到個股漲跌，卻看不到最關鍵的事：**錢正在從哪裡流向哪裡**。美股強還是新興市場強？資金在進黃金還是進債券？這些「輪動」訊號散落在幾十個標的裡，靠肉眼盯盤根本拼不出全貌。

RRG（相對輪動圖）就是為此而生的圖表：把每個資產相對大盤的強弱與動能畫在四個象限裡（領先、轉弱、落後、轉強），資金的流向一目瞭然。但市面上的 RRG 工具不是要付費，就是不能自訂標的。

## 我的解法

自己做一個，而且**全自動**：

- 三組視角：全球資產輪動（股、債、金、原物料、比特幣）、美股 11 大板塊、全球主要市場（美歐日台陸韓印）
- 三個週期（120/60/20 日），長中短期輪動一次看
- 每個交易日早上 6:30（美股收盤後）由 GitHub Actions 自動抓資料、重算、部署，打開網頁永遠是最新的
- 零維運成本：資料來自 Yahoo Finance，網站掛在 GitHub Pages，全程免費

## 幕後技術

Python 純標準庫（不依賴任何套件）計算 JdK RS-Ratio 的開源近似，輸出單一自包含 HTML；GitHub Actions 排程自動更新。
